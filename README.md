# Web Scraping Portfolio

Python scrapers I've built to extract and structure data from websites, with clean CSV output ready for analysis or use.

## Projects

### 1. Quotes Scraper (`quotes_scraper.py`)
Scrapes quotes and authors across multiple pages with pagination handling.
- Handles unlimited pages automatically until no more content is found
- Includes error handling for failed requests
- Respects the server with a polite delay between requests
- Output: `quotes.csv` (100 quotes)

### 2. Books Scraper (`books_scraper.py`)
Scrapes book titles, prices, and star ratings from an online bookstore.
- Extracts data from HTML attributes, not just visible text
- Handles pagination until the last page is detected
- Output: `books.csv`
